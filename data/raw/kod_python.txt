Python'da for döngüsü nasıl yazılır?
<assistant>
for döngüsü, bir dizinin elemanları üzerinde tekrarlamak için kullanılır. Örnek:
for i in range(5):
    print(i)
Bu kod 0'dan 4'e kadar olan sayıları yazdırır. range(5) fonksiyonu 0, 1, 2, 3, 4 değerlerini üretir. Döngü gövdesi girintili yazılmalıdır.

Python'da if koşulu nasıl kullanılır?
<assistant>
if koşulu, bir şart doğruysa belirli kodu çalıştırır. Örnek:
yas = 18
if yas >= 18:
    print("Reşitsiniz")
else:
    print("Reşit değilsiniz")
Burada yas 18 veya daha büyükse ilk mesaj, değilse else bloğundaki mesaj yazdırılır. elif ile ek koşullar eklenebilir.

Python'da bir dosya nasıl okunur?
<assistant>
Dosya okumak için open fonksiyonu ve with bloğu kullanılır. Örnek:
with open("notlar.txt", "r", encoding="utf-8") as dosya:
    icerik = dosya.read()
print(icerik)
with bloğu, işlem bitince dosyayı otomatik kapatır. encoding="utf-8" Türkçe karakterlerin doğru okunmasını sağlar. "r" kipi okuma anlamına gelir.

Python'da liste elemanları nasıl filtrelenir?
<assistant>
Liste comprehension ile filtreleme yapılabilir. Örnek:
sayilar = [1, 2, 3, 4, 5, 6]
ciftler = [x for x in sayilar if x % 2 == 0]
print(ciftler)
Bu kod çift sayıları seçer ve [2, 4, 6] üretir. if koşulu yalnızca şartı sağlayan elemanları yeni listeye alır.

Python'da while döngüsü ile sayaç örneği yaz ve açıkla.
<assistant>
Örnek:
sayac = 0
while sayac < 5:
    print(sayac)
    sayac += 1

Python'da hata yönetimi nasıl yapılır?
<assistant>
try ve except bloklarıyla hata yönetimi yapılır. Örnek:
try:
    sonuc = 10 / 0
except ZeroDivisionError:
    print("Sıfıra bölme hatası")
try bloğunda hata oluşursa except bloğu çalışır. Bu, programın çökmesini engeller. Belirli hata türünü yakalamak, beklenmeyen hataları gizlemekten daha güvenlidir.

Python'da bir sayının asal olup olmadığını nasıl kontrol ederim?
<assistant>
Bir sayının asal olması için 1'den büyük olması ve yalnızca 1'e ve kendisine bölünmesi gerekir. Örnek:
def asal_mi(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True
Bu fonksiyon 2'den sayının kareköküne kadar bölen arar. Bölen bulunursa asal değildir. Kareköke kadar kontrol etmek yeterlidir ve işlemi hızlandırır.
